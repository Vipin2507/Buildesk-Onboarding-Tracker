How activity is measured

An account counts as using CRM when it has a follow-up, visit, booking, other workflow action, or call-log activity. Lead receipt alone is shown separately as “Lead receiving, no activity” and does not make the account active. Call counts come from GetCallLogReportCountUserwise. Reports are cached locally by account and date range, so reopening the same report does not repeat the API requests. Consecutive-day cards use saved single-day reports and remain incomplete until enough daily history is available.
